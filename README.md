# Weil Baseline — prototype

A working prototype of a player development platform, built as a concept for
Weil Tennis Academy. Single self-contained page: Parent, Student, Coach and
Director views, all interactive.

All players, ratings, hours and messages are **fictional sample data**.

## Deploy to GitHub Pages

1. Create a new repository — name it something unguessable, e.g.
   `wb-preview-8fa3c1`. Public is fine (see the note below); private repos
   need GitHub Pro to serve Pages.
2. Upload every file in this folder to the repository root:
   `index.html`, `favicon.png`, `og.png`, `robots.txt`, `.nojekyll`
3. Repository **Settings → Pages**
4. Source: **Deploy from a branch** · Branch: **main** · Folder: **/ (root)** · Save
5. Wait about a minute. The URL appears at the top of that page:
   `https://<your-username>.github.io/<repo-name>/`

## Before you send the link

- Open it on a phone as well as a laptop.
- The page carries `noindex` and a `robots.txt` disallow, so search engines
  should skip it — but **the URL itself is public**. Anyone with the link can
  open it. Do not treat it as access-controlled.
- To make it genuinely private, see the Cloudflare note in the covering message.
